# AutoWords

**以字数为准的 KOReader 自动翻页插件。**

AutoWords 不看固定秒数，而是看**当前屏幕上到底有多少字**来决定什么时候翻页：
密密的整页多停一会儿，只有三行的短页少停一会儿。阅读速度可以直接用**你正在看的这一页**
校准出来。

*Read this in [English](README.md).*

---

## 为什么还要再造一个自动翻页

KOReader 自带 **AutoTurn**，每隔固定秒数翻一页。固定秒数永远要折中：按密页调好，
短页就显得磨蹭；按短页调好，密页还没读完就翻过去了。

AutoWords 改成按字数计时，每页单独算：

```
本页停留时间 = 本页可见文字数 / 阅读速度 * 60 秒
```

## 功能

| | |
| --- | --- |
| 📖 **按字数计时** | 每次翻页的时间由当前屏幕上实际可见的文字量决定 |
| 🎯 **当场校准** | 设置界面始终显示本页字数和对应停留时间；「以本页校准」只要输入一个秒数就能反推速度 |
| 🔤 **两种计数口径** | **字数**（每个非空白 UTF-8 字符算 1，对中文直观）或 **词数**（中文逐字、西文按单词） |
| ⏱️ **下限与上限** | 最短停留（纯图片页很有用）、最长停留 |
| 👆 **触摸后重新计时** | 触摸屏幕后，本页倒计时重新开始 |
| 📐 **翻页距离** | 每次移动多少屏（滚动模式下支持小数） |
| 📖 **逐句导引** | 可选模式：一句一句地走，在正在读的句子下面画一条线（不写入标注、不进列表） |
| 🅰️ **状态栏图标** | 顶部（Alt status bar）和/或底部状态栏上的小标记，只在运行时显示 |
| 🎛️ **手势 / 快捷键** | 注册为 KOReader 动作：`AutoWords: start/stop`、`AutoWords: settings` |
| 🩺 **诊断信息** | 一个对话框列出所有关键状态，图标不显示时用它排查 |
| 🌐 **界面本地化** | 跟随 KOReader 界面语言；内置英文与简体中文 |

## 环境要求

- **KOReader**：针对当前 `master` 源码开发与核对。
- **只支持可重排文档**：EPUB、FB2、TXT、HTML 等由 crengine 渲染的格式。
  PDF 与 DJVU 会被**显式识别并拒绝**——那里的文字无法低成本统计，插件会直接告诉你，
  而不是静默地乱翻。
- **顶部状态栏是可选的**，需要先在 KOReader 里启用 **Alt status bar**。

## 安装

仓库根目录**就是**插件目录，所以安装就是把仓库克隆进 KOReader 的 `plugins` 目录，
最终得到 `plugins/autowords.koplugin/`：

```sh
cd <KOReader 安装目录>/plugins
git clone https://github.com/khhf/autowords.koplugin.git
```

也可以从 [Releases 页面](https://github.com/khhf/autowords.koplugin/releases) 下载 ZIP，
解压后让插件文件位于 `plugins/autowords.koplugin/`。

然后**完全重启 KOReader**——返回书架不算。

| 平台 | `plugins` 目录 |
| --- | --- |
| Kindle | `/mnt/us/koreader/plugins/` |
| Kobo | `.kobo/koreader/plugins/` |
| PocketBook | `applications/koreader/plugins/` |
| Android | `/sdcard/koreader/plugins/` |
| Linux / macOS | `<KOReader 安装目录>/plugins/` |

纯 Lua，不需要编译。如果重启后菜单里没有出现，去 KOReader 菜单里的「插件管理」确认一下。

## 使用

1. 打开一本书，**顶部菜单 → 导航 → AutoWords**。
2. 对话框会显示 AutoWords 量到的结果：

   ```
   本页：486 字
   阅读速度：300 字/分钟
   → AutoWords 在此页停留 97.2 秒
   ```

3. 点「**以本页校准**」，输入你读完这一页需要多少秒——比如 80 秒，
   速度就反推出来并保存（486 ÷ 80 × 60 ≈ 365 字/分钟）。
4. 点「**开始**」。之后每一页都会被单独统计与计时，状态栏上会出现一个小图标。
   点「**停止**」结束，图标立即消失。

### 状态栏图标

默认放在**顶部状态栏**（KOReader 的 *Alt status bar*）。crengine 会把那一整串文字
**右对齐**绘制，所以插件的内容自然落在**右侧块的左端、页码之前**：

```
┌──────────────────────────────────────────────┐
│ 书名 · 章节                        Ⓐ 12/240  5.0% │
├──────────────────────────────────────────────┤
│                                              │
│                  正文 …                      │
│                                              │
└──────────────────────────────────────────────┘
```

「更多设置 → 图标位置」可以在 **顶部 / 底部 / 两者 / 不显示** 之间切换。
**默认只用顶部，是为了完全不碰底部状态栏**（原因见下面「实现说明」）。

- **顶部**栏需要先在 KOReader 里启用 Alt status bar（阅读菜单里），
  没启用时那一栏根本不存在，自然也没有图标。
- **底部**栏的图标对应 KOReader 状态栏设置里的「**外部内容 / External content**」这一项
  ——官方给第三方插件的接口，自带的 SSH、ReadTimer 插件用的也是它。
- **图标不能点**：KOReader 给自己状态栏点击的优先级更高（顶部＝打开菜单，
  底部＝切换状态栏模式），插件抢不过。要打开设置请走菜单，或把 `AutoWords: settings`
  绑到手势/快捷键。
- 如果图标显示成**空心方框**，说明当前字体没有这个字形，去「更多设置 → 图标字符」
  换一个；`(A)`、`[A]`、`A` 是纯 ASCII，任何字体都有。

## 实现说明

### 怎么量文字

AutoWords 统计的是**当前可见区域**的文字
（`document:getTextFromPositions({x=0,y=0}, {x=屏幕宽, y=屏幕高}, true)`）——
这正是 KOReader 自己状态栏"本页行数/字数"用的那个调用。滚动模式下这是唯一有意义的口径，
而且换字号、改页边距、换排版之后字数会自动跟着变。

> `document:getPageText()` 看起来才是"正确"的接口，但它是个陷阱：基类实现里调用
> `self._document:openPage()`，而 **crengine 的文档对象没有这个方法**——在 EPUB 上会直接
> 抛 `attempt to call a nil value (method 'openPage')`。它是给 MuPDF 后端准备的，
> 而且在那边返回的也不是字符串。

计数本身是对取回来的字符串做一遍线性扫描（`autowords_count.lua`，不建中间表），
两种口径就是上面表格里的「字数 / 词数」。

### 怎么计时

`字数 / 速度 * 60` 秒，再按最短/最长停留钳制。结果交给 `UIManager:scheduleIn()`——
和自带 AutoTurn 用的是同一套定时器。

**没有任何轮询**：每页算一次延迟、挂一个回调，到点翻页，然后量新的一页。空闲时开销为零。
运行期间会设置 `PluginShare.pause_auto_suspend`，避免读到一半被自动休眠打断。

翻页（包括手动翻页）会以 `PageUpdate` / `PosUpdate` 事件到达并重新计时，
所以手动翻过去之后不会还要干等上一页的定时器。到文档末尾时
（向前翻但没有产生位移，或收到 crengine 的 `EndOfBook` 事件）插件会自己停下，而不是空转。

### 状态栏图标是怎么放上去的

两条状态栏都**放不下插件的控件**，能加的只有文本：

- 底部栏由 `ReaderFooter:genFooterText()` 生成、渲染成**一个 TextWidget**；
  插件通过 `ReaderFooter:addAdditionalFooterContent(func)` 贡献内容（SSH、ReadTimer 用的就是它，
  这也是那一项叫「外部内容」的原因）。
- 顶部 **Alt status bar 是 crengine 自己画的**：KOReader 把一串字符串交给它
  （`ReaderCoptListener:updatePageInfoOverride()`），插件通过
  `crelistener:addAdditionalHeaderContent(func)` 拼在**最前面**。crengine 把整串**右对齐**绘制，
  所以拼在最前面的图标就落在了右侧块的左端。

`ReaderFooter:addAdditionalFooterContent()` 有一个值得知道的副作用：**第一次调用时**
它会重建模式索引并执行 `updateFooterTextGenerator()`，而这个函数会把 `footer.mode`
改写成"第一个已启用的项目"。因此 AutoWords（1）只有在你明确选择底部时才注册，
（2）注册时机放在文档就绪之后而不是插件 `init()` 期间，（3）调用前后保存并恢复
`footer.mode`。

### 开销

每次翻页一次 crengine 文本提取 + 一遍线性扫描，仅此而已——没有比翻页本身更快的定时器，
也没有逐帧的工作。图标是文本，绘制成本对 KOReader 来说等于零。

### 逐句导引

「逐句导引」是第二种阅读模式（两种模式互斥）：不再按整页计时，而是一句一句地走，
并在正在读的那句下面保持一条横线。

- **句子边界来自 crengine 本身**：`document:extendXPointersToSentenceSegment()`，
  也就是 KOReader 自己「把选区扩展到整句」用的那个调用。下一句的起点就是上一句的终点，
  不会漏读也不会重复，也不需要正则去猜"什么算一句话"。
- **这条横线不是标注。** 它走的是 KOReader 的**临时高亮**
  （`view.highlight.temp` 配合 `view.highlight.temp_drawer = "underscore"`），
  也就是查词时用的那套机制。临时高亮只画在屏幕上、从不写入文档设置，
  所以**本插件画的任何东西都不会出现在书签/标注列表里**，
  以后导出标注时也不会多出内容。
- **节奏**＝句子本身的阅读时间 + 读者自然会有的停顿：

  ```
  停留 = 字数 / 速度 * 60
       + 逗号 × 0.15 秒 + 分号 × 0.25 秒 + 破折号 × 0.15 秒
       + （句子结束 ? 0.4 秒）
       + （段落结束 ? 0.6 秒）
  ```

  再与「最短句停留」（默认 0.8 秒）取大——没有这一条，对话密集的页面上横线会飞快往下跑。
  「标点停顿」这一个倍率可以整体缩放上面所有的标点项（0 = 标点不停顿，2 = 加倍）。
- **滚动**：当前句如果快要落到可用高度的下 2/3 以下（或已经滚出屏幕上方），
  画面会滚动到让这句停在距顶部约 1/3 的位置，句子下方始终留有内容。
- **手动控制**：把手势绑到 *AutoWords：下一句* / *AutoWords：上一句* / *AutoWords：暂停/继续*
  就能手动驱动。触摸屏幕会重新计时当前句；暂停时横线留在原处，可以放心走开再回来。

## 已知限制

1. **不支持 PDF / DJVU / 图片型文档**：那里量不到文字，插件会识别并拒绝启动，而不是猜。
2. **顶部状态栏只在分页模式下存在**，并且需要启用 KOReader 的 *Alt status bar*；
   crengine 在滚动模式下不绘制它。
3. 统计的是**可见区域**：双栏模式下是两栏之和，正文流里的页眉页码也会被计入。
4. 取不到文字时（纯图片页、文档还在排版）按 0 字处理，套用**最短停留**，不会卡住。
5. **菜单和对话框会让翻页暂停**：上层有别的窗口时，插件每 2 秒重试一次，而不是在菜单背后翻页。
6. 阅读速度是一个数字——用「以本页校准」定一次就能贴合你的语言与排版；
   默认的 300 字/分钟只是个猜测值。
7. 界面文案的本地化（KOReader 需要 `.po` 目录文件，用户侧插件装不了）由插件内置的
   简体中文对照表完成，其余语言回退到 KOReader 自己的翻译。

8. **逐句导引只在可重排文档里可用**（依赖 crengine 的句子 xpointer）；PDF / DJVU 下该模式会被拒绝。
9. 横线每几秒移动一次、走局部刷新；电子墨水屏上如果残影明显，把「最短句停留」调大会明显改善。
10. 查词/选词时 KOReader 也用同一套临时高亮，会短暂盖住横线，之后会自己回来。

## 排错

**图标不显示。** 打开「更多设置 → 诊断信息」，里面会列出：

- `插件已加载`、`正在运行`——插件到底启动了没有？
- `图标位置`——是不是设成了「顶部」但 Alt status bar 没开？
- `找到状态栏` / `状态栏可见`——底部栏在不在、显示着没有？
- `顶部状态栏（Alt）`——这本书有没有启用 Alt status bar？
- `状态栏内容已注册` / `顶部状态栏内容已注册`——注册成功了没有？
- `本页文字`——文字测量有没有取到东西？

**底部状态栏变了或看起来不对劲。** KOReader 的 `addAdditionalFooterContent()`
第一次被使用时会把状态栏模式重算一遍（见上面的「实现说明」）。把「图标位置」
保持在**顶部**，或者在 KOReader 的状态栏设置里取消勾选「外部内容」。

**翻得太早 / 太晚。** 在一张有代表性的页面上用一次「以本页校准」，并检查「计数方式」：
同样一段英文，按**字数**统计大约是按**词数**的五倍。
